# Интернет-магазин «Web-Larёk»
«Web-Larёk» — это интернет-магазин с товарами для веб-разработчиков, где пользователи могут просматривать товары, добавлять их в корзину и оформлять заказы. Сайт предоставляет удобный интерфейс с модальными окнами для просмотра деталей товаров, управления корзиной и выбора способа оплаты, обеспечивая полный цикл покупки с отправкой заказов на сервер.

## Архитектура приложения

Код приложения разделен на слои согласно парадигме MVP (Model-View-Presenter), которая обеспечивает четкое разделение ответственности между классами слоев Model и View. Каждый слой несет свой смысл и ответственность:

Model - слой данных, отвечает за хранение и изменение данных.  
View - слой представления, отвечает за отображение данных на странице.  
Presenter - презентер содержит основную логику приложения и  отвечает за связь представления и данных.

Взаимодействие между классами обеспечивается использованием событийно-ориентированного подхода. Модели и Представления генерируют события при изменении данных или взаимодействии пользователя с приложением, а Презентер обрабатывает эти события используя методы как Моделей, так и Представлений.

### Базовый код

#### Класс Component
Является базовым классом для всех компонентов интерфейса.
Класс является дженериком и принимает в переменной `T` тип данных, которые могут быть переданы в метод `render` для отображения.

Конструктор:  
`constructor(container: HTMLElement)` - принимает ссылку на DOM элемент за отображение, которого он отвечает.

Поля класса:  
`container: HTMLElement` - поле для хранения корневого DOM элемента компонента.

Методы класса:  
`render(data?: Partial<T>): HTMLElement` - Главный метод класса. Он принимает данные, которые необходимо отобразить в интерфейсе, записывает эти данные в поля класса и возвращает ссылку на DOM-элемент. Предполагается, что в классах, которые будут наследоваться от `Component` будут реализованы сеттеры для полей с данными, которые будут вызываться в момент вызова `render` и записывать данные в необходимые DOM элементы.  
`setImage(element: HTMLImageElement, src: string, alt?: string): void` - утилитарный метод для модификации DOM-элементов `<img>`


#### Класс Api
Содержит в себе базовую логику отправки запросов.

Конструктор:  
`constructor(baseUrl: string, options: RequestInit = {})` - В конструктор передается базовый адрес сервера и опциональный объект с заголовками запросов.

Поля класса:  
`baseUrl: string` - базовый адрес сервера  
`options: RequestInit` - объект с заголовками, которые будут использованы для запросов.

Методы:  
`get(uri: string): Promise<object>` - выполняет GET запрос на переданный в параметрах ендпоинт и возвращает промис с объектом, которым ответил сервер  
`post(uri: string, data: object, method: ApiPostMethods = 'POST'): Promise<object>` - принимает объект с данными, которые будут переданы в JSON в теле запроса, и отправляет эти данные на ендпоинт переданный как параметр при вызове метода. По умолчанию выполняется `POST` запрос, но метод запроса может быть переопределен заданием третьего параметра при вызове.  
`handleResponse(response: Response): Promise<object>` - защищенный метод проверяющий ответ сервера на корректность и возвращающий объект с данными полученный от сервера или отклоненный промис, в случае некорректных данных.

#### Класс EventEmitter
Брокер событий реализует паттерн "Наблюдатель", позволяющий отправлять события и подписываться на события, происходящие в системе. Класс используется для связи слоя данных и представления.

Конструктор класса не принимает параметров.

Поля класса:  
`_events: Map<string | RegExp, Set<Function>>)` -  хранит коллекцию подписок на события. Ключи коллекции - названия событий или регулярное выражение, значения - коллекция функций обработчиков, которые будут вызваны при срабатывании события.

Методы класса:  
`on<T extends object>(event: EventName, callback: (data: T) => void): void` - подписка на событие, принимает название события и функцию обработчик.  
`emit<T extends object>(event: string, data?: T): void` - инициализация события. При вызове события в метод передается название события и объект с данными, который будет использован как аргумент для вызова обработчика.  
`trigger<T extends object>(event: string, context?: Partial<T>): (data: T) => void` - возвращает функцию, при вызове которой инициализируется требуемое в параметрах событие с передачей в него данных из второго параметра.

#### Класс Buyer

Содержит логику хранения, изменения и валидации данных покупателя. Используется при оформлении заказа для работы с информацией о способе оплаты, адресе доставки, электронной почте и номере телефона. При изменении данных генерирует событие, уведомляющее остальные части приложения об обновлении информации.

Конструктор:  
`constructor(events: IEvents)` - принимает объект брокера событий, используемый для уведомления приложения об изменении данных покупателя.

Поля класса:  
`data: IBuyer` - объект, содержащий данные покупателя:
- `payment: TPayment | null` - выбранный способ оплаты.
- `email: string` - адрес электронной почты покупателя.
- `phone: string` - номер телефона покупателя.
- `address: string` - адрес доставки.

`events: IEvents` - объект брокера событий, используемый для генерации события `buyer:changed`.

Методы класса:  
`setPayment(payment: TPayment): void` - устанавливает способ оплаты покупателя и инициирует событие `buyer:changed`.

`setEmail(email: string): void` - устанавливает адрес электронной почты покупателя и инициирует событие `buyer:changed`.

`setPhone(phone: string): void` - устанавливает номер телефона покупателя и инициирует событие `buyer:changed`.

`setAddress(address: string): void` - устанавливает адрес доставки покупателя и инициирует событие `buyer:changed`.

`getData(): IBuyer` - возвращает объект с текущими данными покупателя.

`clear(): void` - очищает данные покупателя, устанавливая значения по умолчанию, и инициирует событие `buyer:changed`.

`validate(): ValidationErrors` - выполняет проверку корректности заполнения данных покупателя и возвращает объект с ошибками валидации. Проверяет наличие способа оплаты, адреса доставки, электронной почты и номера телефона.

`isValid(): boolean` - проверяет корректность данных покупателя. Возвращает `true`, если объект ошибок пуст, иначе возвращает `false`.

#### Класс CommunicationLayer

Содержит методы взаимодействия с сервером. Используется для получения списка товаров и отправки данных оформленного заказа через API.

Конструктор:  
`constructor(api: IApi)` - принимает объект, реализующий интерфейс `IApi`, который используется для выполнения HTTP-запросов.

Поля класса:  
`api: IApi` - объект для выполнения запросов к серверу.

Методы класса:  
`getProducts(): Promise<IProductsResponse>` - выполняет GET-запрос на эндпоинт `/product` и возвращает промис с объектом, содержащим список товаров и их общее количество.

`sendOrder(orderData: IOrderData): Promise<IOrderResponse>` - принимает объект с данными заказа, выполняет POST-запрос на эндпоинт `/order` и возвращает промис с ответом сервера после успешного оформления заказа.

#### Класс Products

Содержит логику хранения и управления данными товаров. Используется для хранения списка товаров каталога, получения товара по идентификатору, выбора карточки товара и уведомления приложения об изменениях с помощью событий.

Конструктор:  
`constructor(events: IEvents)` - принимает объект брокера событий, используемый для уведомления приложения об изменении данных каталога.

Поля класса:  
`productArr: IProduct[]` - массив товаров каталога.

`productCard: IProduct | null` - объект выбранного товара. Может принимать значение `null`, если товар не выбран.

`events: IEvents` - объект брокера событий, используемый для генерации событий изменения каталога.

Методы класса:  
`getProductById(id: string): IProduct | undefined` - принимает идентификатор товара и возвращает объект товара, если он найден в каталоге, иначе возвращает `undefined`.

`setItems(items: IProduct[]): void` - принимает массив товаров, сохраняет его в каталоге и инициирует событие `catalog:changed`, передавая обновленный список товаров.

`getItems(): IProduct[]` - возвращает массив товаров каталога.

`setCard(id: string): void` - принимает идентификатор товара, находит соответствующий товар в каталоге и сохраняет его как выбранную карточку. Если товар не найден, устанавливает значение `null`. После изменения инициирует событие `catalog:card-changed`.

`getCard(): IProduct | null` - возвращает объект выбранного товара или `null`, если товар не выбран.

#### Класс ShoppingCart

Содержит логику управления корзиной покупателя. Используется для добавления и удаления товаров, очистки корзины, подсчета общей стоимости и количества товаров, а также проверки наличия товара в корзине. При изменении содержимого корзины генерирует событие, уведомляющее остальные части приложения.

Конструктор:  
`constructor(events: IEvents)` - принимает объект брокера событий, используемый для уведомления приложения об изменении содержимого корзины.

Поля класса:  
`buyerCart: IProduct[]` - массив товаров, добавленных в корзину покупателя.

`events: IEvents` - объект брокера событий, используемый для генерации события `basket:changed`.

Методы класса:  
`addToCart(product: IProduct): boolean` - принимает объект товара и добавляет его в корзину, если товар имеет цену и отсутствует в корзине. После успешного добавления инициирует событие `basket:changed`. Возвращает `true`, если товар был добавлен, иначе возвращает `false`.

`getCart(): IProduct[]` - возвращает массив товаров, находящихся в корзине.

`deleteProduct(id: string): void` - принимает идентификатор товара, удаляет соответствующий товар из корзины и инициирует событие `basket:changed`.

`clearCart(): void` - очищает корзину покупателя и инициирует событие `basket:changed`.

`priceCart(): number` - вычисляет и возвращает общую стоимость всех товаров, находящихся в корзине.

`quantityProduct(): number` - возвращает количество товаров, находящихся в корзине.

`hasProduct(id: string): boolean` - принимает идентификатор товара и проверяет его наличие в корзине. Возвращает `true`, если товар найден, иначе возвращает `false`.

#### Класс Card

Является базовым классом для отображения карточек товаров. Содержит общую логику работы с элементами карточки, их заполнением данными и обработкой действий пользователя. Используется как базовый класс для других типов карточек приложения.

Конструктор:  
`constructor(container: HTMLElement, buttonSelector?: string)` - принимает корневой DOM-элемент карточки и, при необходимости, селектор кнопки, расположенной внутри карточки.

Поля класса:  
`imageElement: HTMLImageElement` - DOM-элемент изображения товара.

`categoryElement: HTMLElement` - DOM-элемент категории товара.

`titleElement: HTMLElement` - DOM-элемент названия товара.

`priceElement: HTMLElement` - DOM-элемент стоимости товара.

`descriptionElement?: HTMLElement` - DOM-элемент описания товара. Может отсутствовать.

`buttonElement?: HTMLButtonElement` - DOM-элемент кнопки карточки. Может отсутствовать.

`buttonSelector?: string` - селектор кнопки, используемый для поиска кнопки внутри карточки.

Методы класса:  
Класс не содержит публичных методов. Изменение данных карточки осуществляется через сеттеры свойств.

Сеттеры класса:  
`image: string` - устанавливает изображение товара.

`category: string` - устанавливает название категории товара.

`title: string` - устанавливает название товара.

`price: number | null` - устанавливает стоимость товара. Если значение равно `null`, отображается текст `"Бесценно"`.

`description: string` - устанавливает описание товара.

`buttonText: string` - изменяет текст кнопки карточки.

`buttonDisabled: boolean` - изменяет состояние кнопки, включая или отключая её.

`buttonHandler: () => void` - устанавливает обработчик нажатия на кнопку карточки.

`categoryClass: string` - сбрасывает текущие CSS-классы категории и добавляет новый класс оформления.
