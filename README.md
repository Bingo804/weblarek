# Интернет-магазин «Web-Larёk»
«Web-Larёk» — это интернет-магазин с товарами для веб-разработчиков, где пользователи могут просматривать товары, добавлять их в корзину и оформлять заказы. Сайт предоставляет удобный интерфейс с модальными окнами для просмотра деталей товаров, управления корзиной и выбора способа оплаты, обеспечивая полный цикл покупки с отправкой заказов на сервер.

## Архитектура приложения

Код приложения разделен на слои согласно парадигме MVP (Model-View-Presenter), которая обеспечивает четкое разделение ответственности между классами слоев Model и View. Каждый слой несет свой смысл и ответственность:

Model - слой данных, отвечает за хранение и изменение данных.  
View - слой представления, отвечает за отображение данных на странице.  
Presenter - презентер содержит основную логику приложения и  отвечает за связь представления и данных.

Взаимодействие между классами обеспечивается использованием событийно-ориентированного подхода. Модели и Представления генерируют события при изменении данных или взаимодействии пользователя с приложением, а Презентер обрабатывает эти события используя методы как Моделей, так и Представлений.

### Базовый код

#### Класс Component
Является базовым классом для всех компонентов интерфейса.
Класс является дженериком и принимает в переменной `T` тип данных, которые могут быть переданы в метод `render` для отображения.

Конструктор:  
`constructor(container: HTMLElement)` - принимает ссылку на DOM элемент за отображение, которого он отвечает.

Поля класса:  
`container: HTMLElement` - поле для хранения корневого DOM элемента компонента.

Методы класса:  
`render(data?: Partial<T>): HTMLElement` - Главный метод класса. Он принимает данные, которые необходимо отобразить в интерфейсе, записывает эти данные в поля класса и возвращает ссылку на DOM-элемент. Предполагается, что в классах, которые будут наследоваться от `Component` будут реализованы сеттеры для полей с данными, которые будут вызываться в момент вызова `render` и записывать данные в необходимые DOM элементы.  
`setImage(element: HTMLImageElement, src: string, alt?: string): void` - утилитарный метод для модификации DOM-элементов `<img>`


#### Класс Api
Содержит в себе базовую логику отправки запросов.

Конструктор:  
`constructor(baseUrl: string, options: RequestInit = {})` - В конструктор передается базовый адрес сервера и опциональный объект с заголовками запросов.

Поля класса:  
`baseUrl: string` - базовый адрес сервера  
`options: RequestInit` - объект с заголовками, которые будут использованы для запросов.

Методы:  
`get(uri: string): Promise<object>` - выполняет GET запрос на переданный в параметрах ендпоинт и возвращает промис с объектом, которым ответил сервер  
`post(uri: string, data: object, method: ApiPostMethods = 'POST'): Promise<object>` - принимает объект с данными, которые будут переданы в JSON в теле запроса, и отправляет эти данные на ендпоинт переданный как параметр при вызове метода. По умолчанию выполняется `POST` запрос, но метод запроса может быть переопределен заданием третьего параметра при вызове.  
`handleResponse(response: Response): Promise<object>` - защищенный метод проверяющий ответ сервера на корректность и возвращающий объект с данными полученный от сервера или отклоненный промис, в случае некорректных данных.

#### Класс EventEmitter
Брокер событий реализует паттерн "Наблюдатель", позволяющий отправлять события и подписываться на события, происходящие в системе. Класс используется для связи слоя данных и представления.

Конструктор класса не принимает параметров.

Поля класса:  
`_events: Map<string | RegExp, Set<Function>>)` -  хранит коллекцию подписок на события. Ключи коллекции - названия событий или регулярное выражение, значения - коллекция функций обработчиков, которые будут вызваны при срабатывании события.

Методы класса:  
`on<T extends object>(event: EventName, callback: (data: T) => void): void` - подписка на событие, принимает название события и функцию обработчик.  
`emit<T extends object>(event: string, data?: T): void` - инициализация события. При вызове события в метод передается название события и объект с данными, который будет использован как аргумент для вызова обработчика.  
`trigger<T extends object>(event: string, context?: Partial<T>): (data: T) => void` - возвращает функцию, при вызове которой инициализируется требуемое в параметрах событие с передачей в него данных из второго параметра.

#### interface ICartData

`items: any[]` - массив товаров, добавленных пользователем в корзину. Каждый элемент массива содержит информацию о товаре, необходимую для его отображения (например, идентификатор, название и стоимость).

`total: number` - общая стоимость всех товаров, находящихся в корзине.

#### Класс CartView

`constructor(container: HTMLElement)` - принимает DOM-элемент корзины, вызывает конструктор родительского класса `Component`, получает ссылки на основные элементы интерфейса корзины (`.basket__list`, `.basket__price`, `.basket__button`), которые используются для отображения списка товаров, общей стоимости и оформления заказа.

`list` - элемент списка товаров (`.basket__list`). Используется для отображения содержимого корзины. При обновлении корзины список очищается и заново заполняется карточками товаров.

`totalPrice` - элемент общей стоимости (`.basket__price`). Отображает суммарную стоимость всех товаров, находящихся в корзине.

`orderButton` - кнопка оформления заказа (`.basket__button`). Используется для перехода к оформлению заказа. Если корзина пуста, кнопка становится недоступной.

`render(data: ICartData): HTMLElement` - принимает объект с данными корзины и обновляет её содержимое. Если корзина пуста, выводит сообщение «Корзина пуста», устанавливает общую стоимость равной «0 синапсов» и блокирует кнопку оформления заказа. Если корзина содержит товары, очищает список, создает для каждого товара элемент на основе шаблона `#card-basket`, заполняет его порядковым номером, названием и стоимостью товара, а также добавляет обработчик события удаления товара. После формирования списка отображает итоговую стоимость корзины и делает кнопку оформления заказа активной. При нажатии на кнопку оформления заказа генерируется пользовательское событие `cart:order`. После завершения обновления возвращает DOM-элемент корзины.

#### Класс ContactsForm

`constructor(container: HTMLElement, events: IEvents)` - принимает DOM-элемент формы и экземпляр брокера событий `IEvents`. Вызывает конструктор родительского класса `Component`, получает ссылки на элементы формы (`email`, `phone`, кнопку отправки и область отображения ошибок), после чего инициализирует обработчики событий и выполняет первоначальную проверку корректности введённых данных.

`form` - HTML-элемент формы. Используется для обработки события отправки формы.

`emailInput` - поле ввода адреса электронной почты (`input[name="email"]`). Используется для получения и проверки введённого пользователем email.

`phoneInput` - поле ввода номера телефона (`input[name="phone"]`). Используется для получения и проверки введённого пользователем номера телефона.

`submitButton` - кнопка отправки формы (`button[type="submit"]`). Автоматически блокируется, если введённые пользователем данные не прошли проверку.

`errorsElement` - элемент отображения сообщений об ошибках (`.form__errors`). Используется для вывода текста с описанием ошибки валидации.

`events` - экземпляр брокера событий `IEvents`, через который после успешной проверки формы отправляется событие `contacts:submit` с введёнными пользователем контактными данными.

`initEvents(): void` - инициализирует обработчики событий формы. Добавляет обработчики ввода для полей электронной почты и телефона, которые запускают повторную проверку данных при каждом изменении. Также обрабатывает отправку формы: отменяет стандартное поведение браузера, проверяет доступность кнопки отправки и генерирует событие `contacts:submit`, передавая объект с введёнными пользователем контактными данными.

`validate(): void` - выполняет проверку корректности введённых данных. Проверяет наличие символов `@` и `.` в адресе электронной почты, а также минимальную длину номера телефона (не менее 10 цифр). В зависимости от результата проверки активирует или блокирует кнопку отправки формы и отображает соответствующее сообщение об ошибке. При успешной проверке очищает область отображения ошибок.

`render(data: IContactsData): HTMLElement` - принимает объект с контактными данными пользователя, заполняет поля формы значениями электронной почты и телефона, выполняет их повторную проверку с помощью метода `validate()` и возвращает готовый DOM-элемент формы.

#### Класс Modal

`constructor(container: HTMLElement)` - принимает DOM-элемент модального окна, вызывает конструктор родительского класса `Component`, получает ссылки на кнопку закрытия (`.modal__close`) и контейнер содержимого (`.modal__content`), проверяет их наличие и инициализирует обработчики событий. Если один из обязательных элементов отсутствует, генерируется исключение.

`closeButton` - элемент кнопки закрытия модального окна (`.modal__close`). Используется для закрытия модального окна по нажатию пользователя.

`contentElement` - контейнер содержимого модального окна (`.modal__content`). Используется для размещения динамически передаваемого содержимого перед открытием модального окна.

`initEvents(): void` - инициализирует обработчики событий модального окна. Добавляет обработчик закрытия по нажатию на кнопку закрытия, обработчик закрытия по клику на затемненную область вне содержимого модального окна, а также обработчик закрытия по нажатию клавиши **Escape**, если модальное окно открыто.

`render(content: HTMLElement): HTMLElement` - принимает DOM-элемент с содержимым модального окна, очищает контейнер содержимого, добавляет в него переданный элемент, открывает модальное окно и возвращает его DOM-элемент.

`open(): void` - открывает модальное окно, добавляя контейнеру CSS-класс `modal_active`, а также запрещает прокрутку страницы путем установки свойства `overflow: hidden` для элемента `body`.

`close(): void` - закрывает модальное окно, удаляет CSS-класс `modal_active`, восстанавливает возможность прокрутки страницы, очищает содержимое модального окна и подготавливает его к следующему открытию.

`isOpen(): boolean` - проверяет, находится ли модальное окно в открытом состоянии. Возвращает `true`, если контейнер содержит CSS-класс `modal_active`, иначе возвращает `false`.

#### Класс OrderForm

`constructor(container: HTMLElement, events: IEvents)` - принимает DOM-элемент формы оформления заказа и экземпляр брокера событий `IEvents`. Вызывает конструктор родительского класса `Component`, получает ссылки на все необходимые элементы формы (поле ввода адреса, кнопки выбора способа оплаты, кнопку отправки и область отображения ошибок), после чего инициализирует обработчики событий и выполняет первоначальную проверку корректности заполнения формы.

`form` - HTML-элемент формы оформления заказа. Используется для обработки отправки формы.

`addressInput` - поле ввода адреса доставки (`input[name="address"]`). Используется для ввода и последующей проверки адреса доставки.

`submitButton` - кнопка отправки формы (`button[type="submit"]`). Активируется только после успешного заполнения всех обязательных полей формы.

`errorsElement` - элемент отображения сообщений об ошибках (`.form__errors`). Используется для вывода информации о причине невозможности отправки формы.

`cardBtn` - кнопка выбора способа оплаты банковской картой (`button[name="card"]`). При выборе делает данный способ оплаты активным и изменяет оформление кнопок.

`cashBtn` - кнопка выбора способа оплаты наличными (`button[name="cash"]`). При выборе делает данный способ оплаты активным и изменяет оформление кнопок.

`selectedPayment` - хранит текущий выбранный способ оплаты. Используется при проверке корректности формы и передается вместе с адресом при отправке данных.

`events` - экземпляр брокера событий `IEvents`, через который после успешной проверки формы генерируется событие `order:submit` с данными заказа.

`initEvents(): void` - инициализирует обработчики событий формы. Добавляет обработчики выбора способа оплаты, которые сохраняют выбранный вариант, обновляют оформление кнопок и запускают повторную проверку формы. Добавляет обработчик изменения адреса доставки, выполняющий валидацию при каждом вводе символов. Также обрабатывает отправку формы: отменяет стандартное поведение браузера, проверяет доступность кнопки отправки и генерирует событие `order:submit`, передавая адрес доставки и выбранный способ оплаты.

`validate(): void` - выполняет проверку корректности заполнения формы. Проверяет, что пользователь указал адрес доставки и выбрал способ оплаты. Если хотя бы одно из условий не выполнено, блокирует кнопку отправки и выводит соответствующее сообщение об ошибке. При успешной проверке активирует кнопку отправки и очищает сообщение об ошибке.

`render(data: IOrderData): HTMLElement` - принимает объект с данными заказа, заполняет поле адреса, устанавливает ранее выбранный способ оплаты, выполняет повторную проверку формы с помощью метода `validate()` и возвращает готовый DOM-элемент формы.

#### interface ISuccessData

`total: number` - общая стоимость оформленного заказа, которая отображается в сообщении об успешном завершении покупки.

#### Класс SuccessView

`constructor(container: HTMLElement)` - принимает DOM-элемент окна успешного оформления заказа, вызывает конструктор родительского класса `Component`, получает ссылки на элементы отображения информации (`.order-success__description`) и кнопку закрытия (`.order-success__close`), которые используются при работе компонента.

`description` - элемент описания успешного оформления заказа (`.order-success__description`). Используется для отображения сообщения о количестве списанных синапсов после завершения покупки.

`closeButton` - кнопка закрытия окна успешного оформления заказа (`.order-success__close`). Используется пользователем для закрытия окна после ознакомления с результатом оформления заказа.

`render(data: ISuccessData): HTMLElement` - принимает объект с информацией о заказе, отображает в элементе `description` сообщение с общей суммой списанных синапсов в формате «Списано N синапсов» и возвращает готовый DOM-элемент компонента.

`onClose(callback: () => void): void` - принимает функцию обратного вызова (`callback`) и назначает её обработчиком события нажатия на кнопку закрытия. Используется для выполнения необходимых действий после закрытия окна успешного оформления заказа, например закрытия модального окна или очистки данных корзины.
